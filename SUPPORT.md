# Support for SEO-pro

Publisher and maintainer: [Daniel Agrici](https://github.com/AgriciDaniel).

For installation questions, bugs, or privacy questions, open this repository's
**Issues** tab and choose **New issue**. You need a GitHub account to post.
The preview repository is private; after the planned public rollout, its support
tracker will be available to the public. The new public address is recorded in
the package metadata and becomes available only after that rollout.

Include the plugin version, ChatGPT surface, a short example prompt, what
happened, and what you expected. Say which input or tool was unavailable.
Do not publish a full client export, private page, chat transcript, credential,
payment information, or identity document. A small redacted example is enough.

For a privacy or security concern, begin with a high-level issue requesting a
private reporting route. Do not post the sensitive material. No dedicated
private support inbox or response deadline is promised.

For an unavailable upload option or a ChatGPT account error, use
[OpenAI's Help Center](https://help.openai.com/). The plugin maintainer cannot
change your ChatGPT plan, workspace permissions, or OpenAI verification status.
