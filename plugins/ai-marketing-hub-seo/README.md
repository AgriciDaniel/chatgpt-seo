# SEO-pro

Ask for a concrete SEO outcome and supply a URL, draft or export. The plugin
uses available host tools and states what the evidence can establish.

It includes focused workflows for audits, pages, technical SEO, content and
briefs, schema, sitemaps, images, AI search, agent readiness, strategy,
programmatic pages, comparison pages, local SEO, Maps data, international SEO,
Google exports, backlinks, topic clusters, search experience, drift,
ecommerce, FLOW and native image creation/editing. Onboarding and an implementation handoff are included.

Offline helpers process selected files with Python's standard library:
`analyze_html.py`, `validate_sitemap.py`, `analyze_gsc.py`, `scorecard.py`, and
`compare_snapshots.py`, `analyze_crawl.py`, `validate_hreflang.py`,
`inspect_image.py`, and `validate_structured_data.py`. They do not fetch URLs or
contact providers. Detailed decision references and reusable worksheets support
the workflows. FLOW preserves all 41 source routes in a normalized library.

Requested raster images use ChatGPT's integrated image generation/editing tool
when available, with reference-image, transparency and delivery checks.

Account metrics require a supplied export or an independently authorized host
tool. No provider integration or hosted MCP server is bundled. Results do
not guarantee ranking, traffic, indexing, rich results or AI citations.
