# FLOW framework

## Input

A stated FLOW stage or a business/site goal with available evidence.

## Evidence and runtime

If a skill-resource reader fails to open a linked supporting file, try the
available file or execution tool using the installed plugin root returned by
the host or resolved from this skill's location. Do not hardcode a home folder,
version, or working directory. Distinguish a failed reader call from an absent
file, and files actually attempted from files not attempted. Report a resource
as unavailable only after the supported access paths have failed. If no file
or execution access is available, continue within the evidence you can read
and state that limit.

Read [the operating contract](../../references/operating-contract.md) when this
workflow is selected. Use [runtime and data paths](../../references/runtime-and-data.md)
when choosing a tool or handling missing data. Recheck relevant
[search facts and primary sources](../../references/current-search-facts.md)
before date-sensitive claims. For a quantitative diagnostic, read
[scoring](../../references/scoring.md); unavailable categories stay unknown.

## Workflow

1. Credit the framework when using it: Framework adapted from Daniel Agrici, CC BY 4.0, https://github.com/AgriciDaniel/flow. Select a requested stage or route from [the 41-route library](../../references/flow-library.md), which normalizes repeated source prompts and preserves the three distinct Win templates.
2. Find: establish the business goal, audience, existing evidence and useful search opportunities. Mark missing demand or competitor data explicitly.
3. Leverage: identify real strengths, original knowledge, existing useful pages and distribution channels. Do not fabricate authority or case studies.
4. Optimize: select relevant technical, content, local or search-experience changes and their prerequisites. Use the matching bundled workflows for depth.
5. Win: define measurable success, a leading indicator and a validation cadence. Convert the evidence into a prioritized roadmap.
6. For the Local variant use genuine business/profile evidence. Keep the stage worksheet proportional to the request rather than running every workflow.

## Deliverable

An attributed stage worksheet with inputs, findings, decisions, actions and measurable next checks.

## Boundary

All 41 source routes are represented by an adapted catalog, shared stage worksheet and three Win templates. Do not imply 41 distinct prompt bodies, sync a remote library, or infer performance gains from following the framework.
