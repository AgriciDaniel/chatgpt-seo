# OpenAI submission preparation

Prepared on 19 October 2026. Publisher: Daniel Agrici, as an individual.
Package: `ai-marketing-hub-seo`. Display name: SEO-pro. Version: 0.2.13.

## Description to use

Turn a website, page, draft or SEO export into a source-backed diagnosis and
practical action plan. SEO-pro includes technical SEO, content briefs,
structured data, sitemaps, local and international search, ecommerce,
AI-search readiness, and before/after checks. Each finding connects evidence
to a fix and a verification step. Account metrics require a supplied export or
an independently authorized read tool. Image creation uses ChatGPT's integrated
tool when available. No hosted MCP server or paid data integration is bundled.

Source, privacy and support: https://github.com/AgriciDaniel/chatgpt-seo.

The repository replaces the unrelated publisher-site destination. The manifest
contains the full listing and policy paths. Target public URLs are planned
until the authorized rollout; never submit the private preview URL to OpenAI.

## Applicable requirements

- The [plugin guidelines](https://developers.openai.com/plugins/plugin-guidelines)
  apply to skills-only packages: truthful descriptions, useful standalone
  behavior, a published privacy policy, support details, verified publisher
  identity, and compliance with security, privacy, and usage policies.
- The [submission guide](https://developers.openai.com/plugins/deploy/submission)
  separates upload, automated checks, review, approval, and publication.
  Skills-only plugins need no MCP review cases, credentials, or demo video.
- The [listing reference](https://developers.openai.com/plugins/deploy/submission#listing-metadata)
  distinguishes MCP-required URL fields from skills-only metadata validation.
  This candidate supplies product, support, privacy, and terms URLs anyway.
- The [naming guidelines](https://developers.openai.com/plugins/plugin-guidelines)
  discourage generic names and misleading affiliation. The directory name
  stays SEO-pro. Its generic-name review risk is unresolved.
- The [package reference](https://developers.openai.com/plugins/build/plugins)
  describes the portable manifest and bundled resources. Keep secrets and
  private bindings out of author-supplied ZIPs.

These sources were checked on 19 October 2026. A polished README and passing
local checks do not establish eligibility or approval. Skills-only listings
may have additional eligibility requirements.

## Remaining release steps

1. Execute the approved repository rollout; verify the product and policy
   URLs are public and serve the correct content without authentication.
2. Resolve developer identity verification through OpenAI. A support
   specialist escalation is not identity approval.
3. Confirm country targeting and required declarations with the publisher.
   Countries are omitted rather than inferred. The package has no payment
   or checkout operation.
4. Test the exact saved package in the intended host. Complete OpenAI skill
   scans and authorized publisher attestations, then submit for review.

The archive is a locally validated candidate, not an uploaded, submitted,
approved, or published OpenAI release. This task does not update the owner's
private ChatGPT installation.
