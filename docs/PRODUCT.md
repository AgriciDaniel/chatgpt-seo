# SEO-pro

Turn a page, draft, or SEO export into a sourced fix plan inside ChatGPT.

SEO-pro is an independent skills-only plugin by Daniel Agrici. It is not made
or endorsed by OpenAI. Public directory submission and approval are pending.

## What you can do

| Bring | Ask for |
| --- | --- |
| A public URL or supplied HTML | An audit with evidence, priorities, fixes, and verification steps |
| A topic, audience, and known product facts | A content brief, outline, and source checklist |
| A Search Console export | Calculations and opportunities scoped to the supplied rows |
| Markup, sitemap XML, or locale mappings | A bounded syntax, fact-agreement, or consistency review |
| Business, product, keyword, or backlink evidence | Local, ecommerce, strategy, or architecture recommendations |
| An image request and any required references | A requested visual through the host's integrated image tool |

The package includes 27 skills, 19 reference documents, reusable templates,
nine offline commands, and an attributed 41-route FLOW catalog.
[Read the complete capability map](CAPABILITIES.md).

## Example prompts

```text
Review this page for SEO: [URL]. Cite the evidence, prioritize
the fixes, and explain how to verify each change.
```

```text
Create a content brief about [topic] for [audience]. Separate
sourced facts from assumptions and list the evidence we need.
```

```text
Analyze this Search Console CSV. Check its columns and scope,
then calculate clicks and CTR without inventing missing data.
```

## Install and use

Download the versioned plugin ZIP from the repository's README. Upload it
through an eligible ChatGPT account's Plugins interface, add and install it,
then start a fresh chat with SEO-pro selected. Availability and labels depend
on the account and client. The source-code archive is not the plugin ZIP.
[Follow the installation guide](INSTALL.md).

## Tools, limits, and data

The plugin uses browsing, files, execution, and integrated image generation
only when the host exposes them. Supplied files provide alternatives where
applicable. Account analysis requires an export or an independently authorized
read tool. No hosted MCP server, Google OAuth client, paid data integration,
telemetry, or publisher task-data endpoint is bundled.

Offline commands use Python's standard library and do not fetch URLs. Static
HTML cannot establish rendering, indexing, real-user performance, or complete
site coverage. JSON parsing does not establish rich-result eligibility.
SEO-pro does not guarantee rankings, traffic, indexing, or AI citations.
Generated image edits may change exact colors or geometry. Keep original brand
assets and review visual drafts; native generation is not a pixel-exact editor.

ChatGPT and authorized tools process inputs under their own settings and
policies. Do not upload credentials or unrelated sensitive data. The publisher
receives no task inputs through the package. Public GitHub support is separate
from task processing.
