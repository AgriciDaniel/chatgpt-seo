## Tools and evidence

The [runtime contract](../plugins/ai-marketing-hub-seo/references/runtime-and-data.md)
lists all nine standard-library helper commands and their limits. They process
selected files and emit JSON. Two additional modules are shared implementation
utilities, not additional commands. No helper makes a network request.

The package also contains 19 shared references, worksheets, and an attributed
41-route FLOW catalog. Routes are normalized guidance, not 41 unique prompt bodies.
Image generation is the host's integrated capability when available.
